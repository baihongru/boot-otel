# Git Commit 提交规范

## 提交格式

```
<type>: <subject>
```

## 类型说明

| 类型     | 说明                    |
|----------|-------------------------|
| feat     | 新功能                  |
| fix      | 修复bug                 |
| docs     | 文档修改                |
| style    | 格式调整（空格、分号等）|
| refactor | 重构                    |
| perf     | 性能优化                |
| test     | 测试相关                |
| chore    | 构建/工具相关           |

## 示例

```
feat: 添加导航栏
fix: 修复链接跳转问题
docs: 更新README
chore: 配置CI
```
